# DynamicPackage 分层组合与固定种子随机差分测试计划

> **范围与限制。** 本计划只用于 Linux x86-64 上的离线行为研究与仿真。所有候选输入必须先由只读原 ELF 在隔离调试执行副本中双采集 gold，再由恢复端在相同固定条件下逐步进行字节级比较。计划不允许宣称“所有实数输入”“所有平台”或“全部行为”已经穷尽证明；它的目标是系统性扩大有限可审计覆盖。

## 1. 已覆盖基线与观察缺口

当前 H0–H18 已覆盖高偏心／近地轨道、多个日期边界、三个姿态类别、零与非零柔性、DSS 噪声开关、零命令、持续 SADA、组合设备命令以及 H18 的多执行机构脉冲。19 个场景均已完成 100／1000 步原 ELF双采集与恢复端逐步差分。

现有场景并非每一个都具有 global `y[33]` gold；因此，新的组合／随机批次默认必须同时观察 caller `CoreDynamic` 前 264 B、global `y[33]` 264 B、main 544 B 和 IPC payload 3000 B。若某个 gold 采集未包含这四块，则该候选不得被标记为四块 PASS。

## 2. 输入维度与有限域

| 维度 | 离散／受控有效水平 | 现有覆盖摘要 | 新批次策略 |
|---|---|---|---|
| 历法与时间 | 普通日、闰日、年末跨界 | 已覆盖 | 保留为组合轴，而非随机生成非法日期 |
| 轨道 | 近圆 LEO、普通 LEO、高偏心 | 已覆盖 | 与姿态、柔性、命令作配对／三元覆盖 |
| 姿态 | 单位、两个替代、第三四元数 | 已覆盖 | 使用归一化的固定四元数集合 |
| 柔性状态 | 零、稀疏、完整正负振幅 | 已覆盖 | 使用固定有限模板，避免无界随机幅值 |
| 设备命令 | 零、混合、持续 SADA、多执行机构脉冲 | 已覆盖 | 增加固定种子生成的有效命令时间表 |
| 传感器 | 默认、DSS 开关组合与既有参数 | 已覆盖部分 | 在明确的有限开关／参数格点上扩展 |
| 随机种子 | `1`、`12345` | 已覆盖 | 使用额外固定种子，独立于传感器内部随机序列 |

## 3. 分层策略

| 层级 | 方法 | 可接受结论 |
|---|---|---|
| L1：边界组合 | 对小离散维度使用全组合，对连续量只采用明确边界模板 | 指定矩阵中的逐步 bitwise 一致 |
| L2：覆盖阵列 | 对轨道、姿态、柔性、命令、传感器、种子执行 pairwise，并为高风险交互选择三元组合 | 指定覆盖强度和矩阵中的逐步 bitwise 一致 |
| L3：固定种子随机 | 以记录的伪随机算法和种子，在预定义有效范围内生成命令时间表／初态索引 | 该种子序列及生成器版本下的逐步 bitwise 一致 |
| L4：特殊值 | 零、符号翻转、边界角、非有限值仅使用原 ELF先验探针和单独诊断场景 | 已列特殊输入与观察块一致，不泛化 |

## 4. 首个固定种子随机批次：H19

H19 将固定 H18 的日期、近圆 LEO、第三姿态、轮预置和默认传感器配置，以一个完整记录的无符号 32 位线性同余发生器生成 **1000 步有效设备命令时间表**。每一步从发生器状态的比特位选择轮扭矩符号／通道、MTQ 通道、推力器开关、SADA 开关／角目标和惯量更新标志；数值只从事先定义的小幅离散集选取。这样既避免无界浮点 fuzz 输入，也能在原 ELF 和恢复端装配完全相同的命令序列。

H19 使用独立的“命令发生器种子”与传感器 `srand` 种子。两个值、发生器递推式、每一位到字段的映射和数值表必须写入原 ELF probe、恢复端比较器和证据日志；任一处不一致都视为测试装配错误而不是恢复结论。

## 5. 通过准则与阻断规则

每个候选批次必须依次满足以下条件：原 ELF保持 `0400` 和既定 SHA-256；100／1000 步的每个 gold 文件独立采集两次并 `cmp` 一致；恢复端以严格 C11 标志逐步比较四个观察块；存在首个分叉时，仅按“首步—首块—函数反汇编—调试副本诊断—最小修复”的顺序处理；双长度 PASS 后才可进入 Makefile；最后必须以 `make clean && make selftest` 复验并更新矩阵与连续日志。

> 即使 L1–L4 的全部已定义矩阵均通过，结论仍是有限输入域、固定种子、固定平台和固定观察块中的可审计行为等价，而不是对任意输入、任意随机数实现、并发、CPU、编译器、数学库或安全关键环境的数学证明。
