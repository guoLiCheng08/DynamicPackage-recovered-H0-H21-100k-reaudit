# H27：高偏心跨年联合路径的第三固定 LCG 种子

H27 保持 H26 的高偏心跨年、完整柔性、DSS0 噪声、RWheel0 预置和有限有效命令映射不变，仅将命令 LCG 初始种子由 `0x2468ace1` 改为未在既有场景合同中使用的 `0xDEADBEEF`（十进制 `3735928559`）。LCG 递推仍为 `state = state * 1664525 + 1013904223 mod 2^32`，故 H27 提供了相同字段安全边界内的独立多执行机构时间序列。

原 ELF 100/1000 步均执行 first/second 独立采集。四个逐步块和七个终态执行机构快照共 11 个文件在每种长度均逐文件 `cmp` 一致；原 ELF 仍为 mode `0400`、SHA-256 `312678a62afcb64ff9d198d7311db39bece432702cdfb00830d8439d24906403`。

恢复 C 的 100/1000 步比较器分别产生 411 与 4,011 条零字节比较记录。`make check-h27-third-seed-cross-command` 输出 2 条 PASS；修复 Makefile 独立门禁重复规则后，空构建 `make clean && make selftest` 输出 328 个测试可执行项、319 条 PASS、非零差异 0 且无 Makefile 规则覆盖警告。
