# H21 候选：交叉柔性/单 DSS/多设备命令的第二 LCG 种子

## 选择目的

H20 已经把完整 20 维柔性初态、DSS0 噪声开启/DSS1 关闭、预置飞轮和固定 LCG 有效设备命令表组合到同一条 100/1000 步轨迹中。但 H20 仅使用命令 LCG 初始状态 `0x13579bdf`，不能说明相同离散命令映射在另一条序列中的逐步装配、设备状态累积、刚柔耦合及输出封包一致。

H21 保持 H20 已被独立审计的初态、传感器种子及离散有效命令映射不变，仅将命令 LCG 初始状态替换为 `0x2468ace1`。递推式仍为

```text
state[n+1] = state[n] * 1664525 + 1013904223  (mod 2^32)
```

因此 H21 是一个**独立输入时间序列**，不是无界随机或连续值 fuzz。其命令始终来自已经由 H19/H20 验证过 ABI 字段和数值集合：轮扭矩、可选第二轮扭矩、MTQ、SADA flag/双轴角、推力器使能与惯量更新。

## 固定输入

| 维度 | H21 值 |
|---|---|
| 时间/轨道 | 2025-01-02 03:04:05；`a=7,000,000 m`、`e=0.01` |
| 姿态/角速度 | `(0.5,0.5,-0.5,0.5)`；`(0.001,-0.002,0.003)` rad/s |
| 柔性 | H13/H20 完整正负 20 维模板 |
| DSS | DSS0 高斯噪声开启，DSS1 关闭；`srand(12345)` |
| 设备预置 | RWheel0：`omega=628.4185307179587`，`H=7.981915339118876` |
| 命令 LCG | `0x2468ace1`，乘数 `1664525`，增量 `1013904223`，32 位回绕 |
| 步数 | 100 与 1000 |

## 验证规则

原 ELF 仅通过 `analysis/debug_runner/DynamicPackage.exec_copy` 运行。对 100 步和 1000 步分别连续独立采集两次；所有 gold 文件必须逐文件 `cmp` 相同。恢复端随后逐步比较 caller `CoreDynamic` 前 264 B、global `y[33]` 264 B、main 544 B、IPC payload 3000 B，并比较 RWheel、MTQ、Thruster 及四个推力器三元向量终态。只有原 ELF 双采集与恢复端所有比较均为零字节差异，才允许接入默认 `selftest` 门禁。

> H21 仍只验证当前 Linux x86-64、当前运行时、列明种子和有限离散命令序列；它不构成任意 LCG 种子、连续命令值或全输入域等价证明。
