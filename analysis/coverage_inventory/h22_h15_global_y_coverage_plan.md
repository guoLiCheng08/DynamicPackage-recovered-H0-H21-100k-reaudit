# H22 候选：H15 跨年高偏心路径补齐 Global `y` 逐步覆盖

## 决策

本轮优先为 H15 的 100/1000 步跨年高偏心轨道路径补采并比较 global `y[33]`，而不立即将 H21 的同一第二 LCG 序列从 100,000 步机械扩展至 1,000,000 步。

## 依据

H21 已对近圆轨道、完整 20 维柔性模板、DSS0 噪声、预置飞轮和第二 LCG 命令序列完成 10,000 与 100,000 步四块逐步差分。对同一输入合同继续延长至 1,000,000 步的主要新增维度是时间长度；它不会覆盖新的时间/轨道/状态/命令拓扑。

按四块每步 4,072 B 计算，1,000,000 步最终 gold 约 3.79 GiB；两次独立原 ELF 采集约 7.58 GiB，若保留第一次、第二次及最终 gold 约 11.38 GiB。它适合作为后续稳定性压力测试，而非当前最大边际价值的首选。

H15 使用 2031-12-31 23:59:50、`a=26,560,000 m`、`e=0.65`、非单位姿态和 `srand(12345)`，已在 100/1000 步验证 caller-state、main 与 IPC，但**从未采集或比较 global `y[33]`**。补齐该内部积分状态可新增一个原 ELF 观察块，同时覆盖跨年、高偏心和阴影附近的不同路径。

## 场景合同

| 项目 | 固定值 |
|---|---|
| 时间 | 2031-12-31 23:59:50 |
| 步长 | 0.1 s |
| 轨道 | `a=26,560,000 m`、`e=0.65`、其余根数固定为 H15 已验证值 |
| 姿态 | `(0.5, 0.5, -0.5, 0.5)` |
| 初始角速度 | `(0.0125, -0.00875, 0.00425)` |
| 随机 | `srand(12345)` |
| 设备命令 | 零命令 |
| 长度 | 100 步与 1000 步 |
| 新增观察 | 每步 global `y[33]`，264 B |

## 取证与验收

1. 复制 H15 的 100/1000 步原 ELF GDB probe，各建两个独立重采集 probe，保留既有 state/main/IPC gold 不变。
2. 每次 `dyn_main` 返回后将 `&y` 的 264 B 以独立前缀写出；第一步使用 `dump binary memory`，之后使用 `append binary memory`。
3. 每种长度连续独立采集两次并对 global `y` 文件执行 `cmp`；记录大小和 SHA-256。
4. 从现有 H15 共享恢复端比较器复制独立 H22 100/1000 步比较器，仅增加 global `y` 读取、每步 `compare_blob` 和独立 gold 名称。
5. 先运行两个新目标，再从空构建运行完整 `make selftest`。仅在所有比较为 0-byte mismatch 后，将 H22 证据和矩阵写入本地 Git。

## 执行结果（2026-08-25）

上述五项验收均已完成。100/1000 步均以原 ELF 独立连续采集两次；每种长度的 state、global `y`、main 与 IPC 四块逐文件 `cmp` 一致，新增 state/main/IPC 同时与既有 H15 gold 交叉 `cmp` 一致。恢复端两个 H22 包装器均为四块逐步 0-byte mismatch；`make check-h15-global-y` 输出 2 条 PASS，随后空构建 `make clean && make selftest` 输出 315 条 PASS、非零字节差异 0、显式失败 0，展开 324 个测试可执行项。

完整证据、哈希和统计见 [H22 结果记录](h22_h15_global_y_result_20260825.md)。

## 结论边界

即便 H15 global `y` 补齐并通过，结论仍仅限当前 Linux x86-64、当前运行时、严格构建和列明输入合同。此轮不证明所有高偏心轨道、所有跨年时刻、所有命令、所有随机种子或任意平台的一致性。
