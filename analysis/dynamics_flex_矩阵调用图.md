# `dynamics_flex` 矩阵调用图（静态证据）

对原 ELF 中 `dynamics_flex` 进行本地控制流分析后，确认它不是简单的 Euler 方程包装，而是一个以三维和矩阵描述符为核心的耦合求解器。函数体内存在两段结构相似的矩阵组装／求解流程，之后对三个输出向量执行合并与回写。

| 调用类别 | 在函数中的静态调用次数／位置 | 反推意义 |
|---|---:|---|
| `matrix_trans` | 两次 | 两个矩阵块包含显式转置，不能假设所有耦合矩阵都是对称的。 |
| `blas_gemm` | 两次 | 至少两次矩阵乘法形成中间耦合块。 |
| `matrix_memcpy` | 两次 | 原函数复制工作矩阵而非直接原位消元。 |
| `matrix_sub` | 两次 | 两个构造块采用减法形成有效惯量或耦合矩阵。 |
| `blas_gemv` | 多次 | 将控制／动量／状态向量投影至多个三维或扩展子空间。 |
| `vector3_cross` | 一次 | 明确包含叉乘形式的陀螺／角动量项。 |
| `inv_CAL_M3` | 一次 | 某个 3×3 中间矩阵被显式求逆，而非调用通用线性求解器。 |
| `vector_add` / `vector_memcpy` | 末段 | 将三个分量合并为最终导数／加速度输出。 |

本调用图已确认新版 `dynamic_math` 必须保留：三维向量描述符、3×3 原始求逆、矩阵乘向量、矩阵乘矩阵、转置以及原位加法。当前尚不能将这些静态块安全地命名为原作者的具体物理变量；下一阶段应使用原 ELF 金标的单轮、SADA 与磁力矩器激励，逐块校准每个矩阵的输入输出。
