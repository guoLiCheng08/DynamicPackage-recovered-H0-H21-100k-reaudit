# 核心动力学动态快照证据

## 采集条件

本次快照在私有用户、挂载与网络命名空间中完成，`/dev/shm` 被替换为私有 tmpfs；调试执行的是与原 ELF SHA-256 相同的副本，原文件保持模式 `0400` 且未修改。调试器在首次进入 `CoreDynamic` 后继续执行，并在首次进入 `dynamics_flex` 时记录寄存器、调用栈、栈参数区和关键全局对象，随后终止测试。

## 已确认的真实调用链

```text
main
└── dyn_main
    └── CoreDynamic
        └── RK4_Intergrator
            └── differential_equation
                └── dynamics_flex
```

该运行时调用链与静态反汇编完全相符，证明 `dynamics_flex` 是 33 维 RK4 状态传播中的实际导数子模型，而不是未调用的备用代码。

## CoreDynamic 入口证据

首次 `CoreDynamic` 命中时，指令指针为运行时重定位后的 `0x555555405480`，调用者为 `dyn_main`。其栈上可见若干零值参数区与两个 `pi` 常量，说明调度入口未携带简单标量 API，而是依赖全局状态及打包的局部描述符。

关键全局对象在入口处均已初始化：

| 对象 | 运行时观察 | 推论 |
|---|---|---|
| `DynSat` | 包含 3 维描述符、指针和多个双精度状态值 | 其为动力学状态／参数容器，而不是仅输出缓存。 |
| `Sat+0x4a8` | 3×3 描述符与单位／零初值混合 | 此处是姿态或惯量相关矩阵块。 |
| `Sat+0x898` | 维度 3×10 及多个连续双精度系数 | 与 `dynamics_flex` 起始处首次 `matrix_trans`／`blas_gemm` 所用矩阵一致。 |
| `SatTorque` | 六个 3 维描述符连续存放 | `CoreDynamic` 合成多源力矩的全局容器。 |
| `H_w_B`、`L_c_B` | 各为 3 维描述符 | 与反作用飞轮动量、耦合角动量项有关。 |

## dynamics_flex 入口证据

首次进入 `dynamics_flex` 时，运行时寄存器和栈给出如下事实：

| 观察项 | 证据 | 结论 |
|---|---|---|
| 前六个 ABI 参数 | `rdi`、`rsi`、`rdx`、`rcx`、`r8`、`r9` 均指向相邻的栈局部描述符区域 | 核心函数使用多个向量／矩阵输入输出对象，而非单个连续状态数组。 |
| 额外参数 | 返回地址之后的栈槽保存 `H_w_B`、`L_c_B`、`J_c_B`、`J_c_B_inv` 指针 | 刚体／飞轮／耦合惯量对象通过第 7 个及之后的 ABI 参数传入。 |
| 调用者 | `differential_equation` → `RK4_Intergrator` → `CoreDynamic` | 该函数直接产生状态导数。 |
| `Sat+0x898` | 含 3×10 描述符与系数区 | 第一个耦合矩阵块的输入。 |
| `Sat+0x4a8`、`+0x688`、`+0x9a0`、`+0xa00`、`+0xd38` | 分别被两段 `blas_gemv` 链和最终 10 维输出链引用 | 函数至少同时处理 3 维刚体项和 10 维柔性／扩展项。 |
| `SADA` | 函数入口立即读取 `SADA+0x8`、`+0x10`、`+0x38`、`+0x40` | 太阳翼状态参与惯量或耦合项，而非仅在输出层使用。 |

## 与静态矩阵切片的对应

运行时证据让 `dynamics_flex` 中的两段静态调用序列可被更谨慎地命名为：

1. **3 维刚体有效惯量块：** `Sat+0x898` 转置并与另一个 3×3 块相乘，随后经 `matrix_sub` 构造中间矩阵；多个 3 维向量投影和叉乘形成右端项；最后通过 `inv_CAL_M3` 求逆并以 `blas_gemv` 解出 3 维加速度。
2. **10 维柔性／扩展状态块：** 后半段反复以维度 10 的 `blas_gemv` 投影 `Sat+0x9a0`、`+0xa00` 与 `+0xd38`，再同 3 维状态项做耦合叠加，得到最终扩展状态导数。

这些名称是依据调用形态、对象维度和运行时栈参数给出的**结构性解释**，并不声称已恢复原作者变量名或每一个物理系数。下一步应将这两个块分别写成 C 接口，并用相同快照输入比较 3 维和 10 维导数输出。
