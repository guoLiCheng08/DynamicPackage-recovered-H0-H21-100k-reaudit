# RK4_Intergrator 静态与动态证据记录

`RK4_Intergrator` 位于原 ELF `0x5e90`，实际调用 ABI 为一个 `double` 步长参数（首参数浮点寄存器 `xmm0`）。函数直接读取全局 `y[33]`（`0x2184e0`）和全局时间 `t`（`0x2184c0`），并在结束时调用 `y_q_unit` 对状态前四元数归一化后写回 `y`。

反汇编显示其为经典显式四阶 Runge–Kutta，但数组形成和加权顺序已明确：首先求 `k1=f(t,y)`；`k2=f(t+h/2, y+h·k1/2)`；`k3=f(t+h/2, y+h·k2/2)`；`k4=f(t+h, y+h·k3)`；再按 `y += h/6·(k1 + 2k2 + 2k3 + k4)` 更新。各循环长度固定为 `0x108` 字节，即 33 个双精度元素。结束时 `t` 从初始值加步长一次。

## 首个受控动态探针

通过原 ELF `DynamicInit` 设置步长、2020-01-02 03:04:05 时间、轨道根数、对角惯量 `(10,11,12)` 和质量 100 后，以 `h=0.1` 直接调用积分器。该初始化尚未配置完整刚柔与执行机构输入，因此四元数路径产生 NaN；但位置/速度轨迹保持有限，适合作为后续在恢复 `differential_equation` 后的轨道子块金标。

## 阶段数组映射

反汇编中 `r13`、`r14`、`r15` 分别累积 `h·k1`、`h·k2`、`h·k3`；局部 `rsp+0x360` 保存 `h·k4`。`rsp+0x470` 是每次调用 `differential_equation` 的导数输出缓冲区，`rbx` 是当前试算状态，`rbp` 是最终累加输出。原 ELF 的四次调用时间为 `t`、`t+h/2`、`t+h/2`、`t+h`；最终循环先以 `k1 + 2k2 + 2k3 + k4` 的加法顺序形成权重和，再乘以 `/6` 常量，最后加回全局 `y`。这些顺序将在微分方程完成后直接用于恢复实现，而不会以代数等价但舍入路径不同的闭式表达式替换。
