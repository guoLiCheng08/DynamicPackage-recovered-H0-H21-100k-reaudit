# H0：高偏心反太阳／邻接日期／全柔性 100 步端到端证据

> **范围。** 本文仅证明指定的初始化、姿态、全柔性状态、零设备命令、`srand(12345)` 与共享 IPC backing 下，原 ELF 和恢复端在连续 100 步的可观察块逐字节一致。它不证明其他日期、轨道、命令、随机种子、异常 ABI、并发或无限时域的等价性。

## 场景合同

| 项目 | 固定值 |
|---|---|
| 初始日期时间 | 2031-12-30 23:59:50 |
| 步长 | 0.1 s |
| 轨道根数 | `a=26,560,000 m`、`e=0.65`、非零三维根数 |
| 初始姿态 | `[0.5,-0.5,0.5,0.5]` |
| 初始位置／速度 | `[-12e6,65e6,28e6] m` 与 `[0,2000,0] m/s` |
| 柔性状态 | 20 个模态位置／速度分量为固定非零交替序列 |
| 设备命令 | 零命令帧 |

| IPC | 分配 0xBF0-byte backing，初始化 `pthread_rwlock`，与原 50 步模板一致 |

## 恢复端比较与回归

比较器对每步四个块调用逐字节比较。100 个步骤 × 4 个主块合计 400 个逐步比较块均为 0 byte mismatch。该比较器已接入 `Makefile`。

从空构建目录运行 `make selftest` 后，严格自检的独立可执行门禁由 276 增至 **277**；日志 `analysis/coverage_inventory/h0_hundred_full_clean_selftest.log` 中 H0-100 比较器输出：

```text
dyn_main high-eccentric shadow adjacent-date alternate-quaternion full-flex hundred-step original-ELF compare: PASS (bitwise)
```

## 后续

下一步直接从本场景复制为 H0-1000：不改初始条件、随机种子、命令、共享 IPC 或对象记录顺序，只将循环与 `STEP_COUNT` 从 100 改为 1000，并保持双采集 SHA-256 确定性要求。若首次差异出现，比较器必须记录首次分叉的步号、块、字节偏移及双精度位型，随后以二分短重放定位至 RK4／环境／设备／测量／IPC 的最早责任边界。
